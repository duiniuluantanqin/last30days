# 网页提交的黑名单关键词

网页划词后，会打开 GitHub 的新建文件页面，预填 `blacklist/<关键词哈希>.txt` 和选中的词。文件名使用规范化关键词的 SHA-256，避免不同词之间冲突。

在 GitHub 中确认关键词，选择创建新分支并提交 Pull Request；不要直接提交到默认分支。没有写权限的读者需有权访问仓库，并按 GitHub 提示 fork 后提交 PR。

PR 合并后，下一轮采集会读取本目录所有 `.txt` 文件，与 `config.toml` 的 `filter.blocked_keywords` 共同生效。每行一个关键词，空行忽略；本说明文件不会作为关键词读取。新增规则也会重新筛选已经收录的文章。
